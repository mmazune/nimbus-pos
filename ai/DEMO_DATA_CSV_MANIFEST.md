## Notes

- Current schema does not expose PurchaseOrder or GoodsReceipt models. Use Supplier, VendorBill, StockBatch, and StockAdjustment unless future schema adds PO/GRN tables.
- There is no dedicated Receipt model; BG4.A states receipt ID equals order ID and history comes from audit/order lifecycle. Do not create fake receipt-delivery rows.
- Order modifiers appear represented through order item metadata and modifier catalog references rather than a separate OrderItemModifier model.
- HMS API keys must not be CSV plaintext. Create safe keys through the dev API/service in a later reviewed import step.
