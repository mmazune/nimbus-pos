# What to say when pitching

Every line is a sentence you can say. The last column is the truth about today: **drawn** means the screen exists as an approved drawing; **planned** means it is specified and on the roadmap with that milestone; nothing below is live until its milestone is done. Say "we are building", not "we have", until the status says built.

## The floor and the table
| Say this | Status |
|---|---|
| One tap on a table opens the whole menu. The same screen for the waiter, the cashier and the supervisor; each sees the buttons they are allowed. | drawn, U2 |
| Sixty tables fit on one screen with no scrolling, and a busy night gets tabs for guests who are standing. | drawn, U1 |
| A table tells you its story at a glance: whose it is, how long, how much, late, bill asked, ready to collect. | drawn, U1 |
| A booking that arrives to a full table is seated somewhere else in two taps. | drawn, U4 |
| A waiter going home hands their tables to a colleague; nothing is left hanging. | planned, E3 |

## Taking the order
| Say this | Status |
|---|---|
| Any item is three taps away, or one from Popular. Search finds it from a few letters. | drawn, U2 |
| A second round goes straight to the bar; you never retype the table. "Same again" is one tap. | planned, E1 and U2 |
| When a dish is running out, every waiter sees "3 left" on the button before they promise it. | planned, E2 |
| When it is finished, the button goes grey on every screen at the same moment. | drawn, E2 |

## Kitchen and bar

## Stock that looks after itself
| Say this | Status |
|---|---|
| Every dish sold takes its ingredients out of the kitchen's own store, by the recipe. | planned, E6 |
| When the kitchen fridge runs low, the chef is told and the request to the store is already written for them. | planned, E7, E10 |
| Stock moves from the main store, to a second store if you have one, to the kitchen, and each hand-over is signed with a PIN. | drawn, E7 |
| If twelve buns go missing between the store and the kitchen, the system knows on which trip. | planned, E7 |
| Spoiled, broken, staff meal or missing: the chef records it in seconds, with a reason, and it is on a report by morning. | planned, E6 |
| A dish sent back asks one question, "was it made?", so waste is counted and unmade food goes back to stock. | drawn, E1 |
| The system never stops a sale because the stock record is wrong. The chef says "we have it" and a count is asked for. | planned, E10 |
| You can start with no stock set up at all and add it store by store. | planned, E6 |

## Three things we found in no other product we read
1. A **sold-out log**: what ran out, when, for how long, and the sales it probably cost.
2. **"Was it made?"** on every void, tying waste to the till without extra work.
3. **Approval from the manager's phone** when no supervisor is on the floor.

Careful: this comes from reading five vendors' own help pages, not from using their products. Say "we have not seen this elsewhere", not "nobody has this".
